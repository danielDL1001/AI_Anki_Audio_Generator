# AI Anki Audio Generator

## COMO INSTALAR

### 1. Instale o Anki
Baixe e instale o Anki:
https://apps.ankiweb.net/

### 2. Instale o AnkiConnect
1. Abra o Anki.
2. Clique em Ferramentas.
3. Clique em Complementos.
4. Clique em Obter Complementos.
5. Digite o código:

2055492159

6. Clique em OK.
7. Reinicie o Anki.

### 3. Instale o Docker Desktop
Baixe pelo site oficial:
https://www.docker.com/products/docker-desktop/

Instale normalmente e abra o Docker Desktop.
Aguarde até que ele esteja completamente iniciado.

### 4. Instale o programa
Abra esta pasta e dê dois cliques em:

Instalar.bat

Aguarde a instalação terminar.

## COMO UTILIZAR

1. Abra o Anki.
2. Abra o Docker Desktop.
3. Aguarde o Docker iniciar.
4. Dê dois cliques em Iniciar.bat.
5. Siga as instruções apresentadas na tela.

Não feche o Anki enquanto o programa estiver funcionando.

## PROBLEMAS

Se o programa não funcionar:

1. Verifique se o Anki está aberto.
2. Verifique se o Docker Desktop está aberto.
3. Reinicie o Anki.
4. Tente executar Iniciar.bat novamente.
